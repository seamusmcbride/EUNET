# EUNET

| Folder | What it is |
|---|---|
| `portal/` | ASP.NET Core (.NET 10) portal: sign-in, documents, private AI assistant, cameras, photo editor, dashboard, user admin. `portal/DEPLOY.md` covers your laptop (`docker compose up`), a VM, Google Cloud Run and Azure. |
| `showcase/` | Websites and games (Vite + three.js): Orbit, Atelier, Gravity, Blocks, Bunker, Outpost, and the Control Room dashboard. `npm install && npm run build`. |
| `site/` | The first animated test site. |
