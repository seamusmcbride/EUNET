# EUNET

| Folder | What it is |
|---|---|
| `portal/` | ASP.NET Core (.NET 10) portal for the server: sign-in, documents, cameras, photo editor, dashboard, user admin. See `portal/README.md` to deploy. |
| `showcase/` | Websites and games (Vite + three.js): Orbit, Atelier, Gravity, Blocks, Bunker, Outpost, and the Control Room dashboard. `npm install && npm run build`. |
| `site/` | The first animated test site. |
